# Web de Xeleria

## Archivos
- `index.html`: página completa. Incluye estilos y scripts en un único archivo.
- `assets/hero-xeleria.png`: imagen principal de fondo. Hay que subir también esta carpeta.

## Abrir y modificar
1. En Visual Studio, termina la pantalla de configuración y escoge **Desarrollo web (solo código)**.
2. Abre esta carpeta con **Archivo > Abrir > Carpeta**. Si tu edición de Visual Studio no permite abrirla, usa **Archivo > Abrir > Archivo** y selecciona `index.html`.
3. Edita el archivo y guarda con `Ctrl+S`. Ábrelo en Chrome para ver los cambios. El diseño necesita conexión a internet para cargar Google Fonts.

## Publicar con GitHub Pages
1. Crea un repositorio público nuevo en GitHub, por ejemplo `xeleria-web`.
2. Sube el archivo `index.html` y la carpeta `assets` a la raíz del repositorio.
3. Abre **Settings > Pages** del repositorio. En **Build and deployment**, selecciona **Deploy from a branch** y luego la rama `main` y la carpeta `/(root)`; guarda.
4. En esa misma sección aparecerá el enlace público cuando se complete la publicación. Normalmente tendrá el formato `https://TU-USUARIO.github.io/xeleria-web/`.

## Formulario
El formulario utiliza FormSubmit y dirige solicitudes a `Xeleria172@gmail.com`. Para activarlo, envía una solicitud de prueba desde el enlace publicado y confirma el correo de activación que recibirá esa cuenta. Comprueba también la carpeta de spam. El formulario transmite los datos del cliente al servicio de FormSubmit.

## Pendiente antes de vender
Comprueba los textos y el alcance de cada servicio, añade tus datos comerciales y la información legal que corresponda, y haz una prueba real del formulario. Publicar la web no habilita pagos: los precios se muestran como información y las solicitudes llegan por correo.
